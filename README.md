# RecruitmentHub
## Lab Exercise 4

A full-stack web application built using - **Node.js**, **Express**, and **MongoDB (Mongoose)** with a responsive **Tailwind CSS** frontend. 
The platform provides a modern interface for managing job applicant records and pipeline stages in real time.

---

## Features Implemented

- **Full CRUD Operations**: Create, read, update status, and delete candidate application records.
- **RESTful API**: API endpoints using Express.js.
- **Data Validation**: Validation using Mongoose.
- **Interactive Dashboard**: Responsive UI styled with Tailwind CSS.

---

## Tech Stack

- **Backend**: Node.js, Express.js
- **Database**: MongoDB (using Mongoose)
- **Frontend**: HTML5, JavaScript (Fetch API), Tailwind CSS
